HTML 5 + CSS 3

HTML (HyperText Markup Language) y CSS (Cascading Style Sheets) son la base de la construcción de sitios web. Mientras que HTML proporciona la estructura y el contenido de las páginas web, CSS se encarga de su diseño visual y presentación. Con estos dos lenguajes, puedes crear desde simples páginas web estáticas hasta interfaces modernas y responsivas. En esta clase, aprenderemos cómo funcionan juntos HTML y CSS para desarrollar sitios web que sean atractivos, funcionales y adaptados a diferentes dispositivos.
  1. Introducción a HTML
    • ¿Qué es HTML y para qué se utiliza?
    • Estructura básica de un documento HTML
    • Etiquetas esenciales
    • Listas
    • Tablas - Formularios
  2. Introducción a CSS
    • ¿Qué es CSS y cuál es su función?
    • Diferentes formas de agregar CSS
    • Selectores básicos
    • ropiedades básicas de diseño
  3. Maquetación con CSS
    • Modelos de caja (box model)
    • Introducción a Flexbox
    • Introducción a Grid
    • Sitios Responsivos con CSS
  4. Práctica Final

PHP (Hypertext Preprocessor) es un lenguaje de programación del lado del servidor diseñado para el desarrollo web. Es ampliamente utilizado para crear sitios dinámicos e interactivos, permitiendo conectar aplicaciones web con bases de datos y manejar lógica compleja. Gracias a su simplicidad y flexibilidad, PHP es una de las tecnologías más populares en el desarrollo web. En esta clase, aprenderemos los fundamentos de PHP, cómo integrarlo con HTML, y cómo usarlo para desarrollar aplicaciones web dinámicas.
